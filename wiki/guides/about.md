# About

Izomap is a Paper plugin for isometric photography, printed onto maps, made by [zypec](https://zypec.github.io/).

| | |
|---|---|
| Platform | Paper 26.3 and newer, Java 25 |
| Source | [github.com/zypec/izomap](https://github.com/zypec/izomap) |
| Issues | [github.com/zypec/izomap/issues](https://github.com/zypec/izomap/issues) |

### How it was made

Izomap was designed by zypec and written with Claude, Anthropic's AI model, in Claude Code under zypec's direction: the render engine, the camera and preview, the dialogs, the wiki and this site.

### Credits

The block colors are the vanilla map palette's own. The default grass and foliage color maps are sampled from the game's colormaps; the color corrections were measured from the game's block textures. Minecraft is a trademark of Mojang; Izomap is not affiliated with Mojang or Microsoft.
